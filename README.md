# 🔐 Password Strength Checker



A simple Python tool that checks whether a password is Weak, Medium, or Strong.



## 🚀 Features

- Checks length

- Detects uppercase, lowercase, numbers, and symbols



## 🛠️ Installation

```bash

git clone https://github.com/yourusername/password-strength-checker-.git

cd password-strength-checker-

python password\_checker.py

📌 Example

Input: P@ssw0rd123
Output: Strong
